# Full-page visual storytelling and FIRSTS identity

The landing-page content, order and images are unchanged. Its shared navigation and footer receive the requested logo. Other public pages now carry relevant visual explanations throughout their full length, including lower sections and closing calls to action. All existing written content is retained.

## Logo

An original vector stepped F combines three connected levels in the existing neon pink (#ff1199), sunshine orange (#ff8a00), and lime zest (#c8ff00). It represents successive firsts opening the next level. The reusable component appears in public navigation, footer, onboarding, authentication, six workspace roles, portfolio branding, and the facilitator loading state. `app/icon.svg` supplies the browser icon; `public/brand/firsts-mark.svg` is the reusable standalone asset. Native SVG keeps the mark sharp at every size.
